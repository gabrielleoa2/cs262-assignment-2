# cs262-assignment-2

## What does the Expo default template add to the minimal blank template (compared to Assignment 1)?

It has an example app, navigation, screens, and components.

## How is the styling of the app widgets specified?

The styling is specified using the `StyleSheet.create()` object.

## What does Expo store in the `app/` sub-directory?

It stores `tabs/`, `components/`, `layout.tsx`, and `+not-found.tsx`.

## What does Expo store in the `components/` sub-directory?

It stores `button.tsx` and `image-viewer.tsx`.

## When we `npx expo install` the `expo-image-picker`, what files are changed in the application?

`package.json` and `package-lock.json` are changed.
